# Image Toolkit v7.1

## v7.1 업데이트

- 흰색 포장지/라벨/상품 내부가 배경으로 잘못 삭제되는 문제 수정
- 배경 제거 엔진에 `subjectProtectMask` 추가
- 컬러 인쇄/로고/텍스트/식품 영역을 기준으로 피사체 보호 영역을 먼저 계산
- 보호 영역 안의 흰색·밝은 회색 픽셀은 배경 flood-fill에서 제외
- 이미지 바깥쪽과 연결된 실제 배경만 투명 처리하도록 보정


## v7.2 정밀 상품 패키지 누끼 수정

- 기본 제거 방식을 `상품 패키지 정밀 · 흰 포장/라벨 보호`로 변경
- 흰 포장지, 흰 라벨, 제품 내부의 밝은 영역이 배경으로 날아가지 않도록 피사체 외곽/인쇄 영역 기반 보호 마스크 추가
- 첨부 테스트 기준: 미니 시카고 피자, 한성 해물경단처럼 흰 배경과 흰 포장지가 붙은 상품 이미지 대응
- 저장소에 ZIP 파일이 올라가지 않도록 `.gitignore`에 `*.zip` 추가
