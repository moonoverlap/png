## v8.4 업데이트 - 네모/비네모 상품 자동 분기

- v8.3의 사각 박스 잠금은 피자, 경단, 육포처럼 실제 상품 외곽이 네모난 패키지에만 적용합니다.
- 대파 진공팩처럼 실제 외곽이 굴곡진 상품은 `irregular-ai-shape`로 분기해 AI 형태 마스크를 유지합니다.
- 판정 기준: 박스 내부 순백 여백 비율, 코너 순백 비율, 외곽 구조 신호 연속성.
- 목적: 네모 패키지는 흰 포장/라벨 구멍 방지, 비네모 상품은 바깥 흰 배경이 사각형으로 남는 문제 방지.
